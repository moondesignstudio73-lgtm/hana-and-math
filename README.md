# 하나앤수학학원 홈페이지

독립 프로젝트로 제작한 반응형 홈페이지 디자인 시안입니다.

## 실행

Node.js 설치 후 `npm run build`, `npm run check`, `npm start`를 실행합니다. 별도 패키지 설치는 필요하지 않습니다. GitHub Pages 배포 대상은 `main` 브랜치의 `/docs`입니다.

## 구성

- 처음으로: 도형 일러스트, 학습 이야기, 블로그 연결
- 학습 이야기: 질문·탐구·설명을 주제로 한 제안 콘텐츠
- 학원 소식: 사용자 제공 블로그 연결
- 상담 안내: 상담 전 준비 항목 및 FAQ
- 모바일 메뉴, 키보드 탐색, 움직임 줄이기 설정 대응

## 확인 상태

학원명과 블로그 주소는 사용자 제공 정보입니다. Naver 원문 직접 열람이 도구의 사이트 접근 정책에 의해 차단되었습니다. 독립 검색 결과에서 해당 블로그가 다른 학원명으로도 연결되어 있어 학원 소재지·연락처·운영 학년·수업료·강사 정보는 확정하지 않았습니다. 확인되지 않은 정보, 성과, 수강 후기, 실사 사진은 게시하지 않았습니다.

현재 홈페이지는 상단에 디자인 시안임을 표시하고 검색 색인을 제한합니다. 교육 관련 본문은 제안 문구이며 실제 교육과정이라고 주장하지 않습니다. 사업 정보 검증 후 공식 운영본으로 전환해야 합니다.

열림협동조합 기존 프로젝트의 여백, 글자 위계, 메뉴와 버튼 구성 원칙을 참고했습니다. 타사 사진이나 소스 코드는 복제하지 않았습니다. 도형 일러스트와 워드마크는 이번 시안용으로 제작했으며 공식 로고가 아닙니다.

## 콘텐츠 수정

`build.mjs`의 문구를 수정한 후 `npm run build`로 docs를 갱신합니다. 스타일은 `styles.css`, 동작은 `app.js`에서 관리합니다. 배포 전 `npm run check`를 실행합니다. 이 프로젝트는 정적 안내 사이트이며 회원·결제·개인정보 수집 기능은 없습니다.
