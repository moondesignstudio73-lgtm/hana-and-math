# 하나앤수학학원 홈페이지

독립 프로젝트로 제작한 반응형 홈페이지 디자인 시안입니다.

## 실행

Node.js 설치 후 `npm run build`, `npm run check`, `npm start`를 실행합니다. 별도 패키지 설치는 필요하지 않습니다. GitHub Pages 배포 대상은 `main` 브랜치의 `/docs`입니다.

## 구성

- 처음으로: 두 도형의 넓이를 비교하는 수학 노트 표지와 학습 가이드
- 학습 노트: 직접 조작하는 둘레·넓이 도형과 풀이
- 학원 소식: 사용자 제공 블로그 연결
- 상담 안내: 개인용 상담 준비 메모 생성·복사 및 FAQ
- 모바일 메뉴, 키보드 탐색, 움직임 줄이기 설정 대응

## 확인 상태

학원명과 블로그 주소는 사용자 제공 정보입니다. Naver 원문 직접 열람이 도구의 사이트 접근 정책에 의해 차단되었습니다. 독립 검색 결과에서 해당 블로그가 다른 학원명으로도 연결되어 있어 학원 소재지·연락처·운영 학년·수업료·강사 정보는 확정하지 않았습니다. 확인되지 않은 정보, 성과, 수강 후기, 실사 사진은 게시하지 않았습니다.

현재 홈페이지는 하단에 디자인 시안임을 표시하고 검색 색인을 제한합니다. 교육 관련 본문은 제안 문구이며 실제 교육과정이라고 주장하지 않습니다. 사업 정보 검증 후 공식 운영본으로 전환해야 합니다.

2차 디자인은 열림협동조합의 실제 공개 화면(https://yeollimcoop.ivyro.net/review/index.html)을 열어 확인했습니다. 넓은 사진, 명확한 글자 위계, 여백 중심의 구성을 참고했고, 학원에 맞게 블루·옐로 포인트와 공책을 닮은 학습 콘텐츠로 재구성했습니다. 열림의 사진이나 소스 코드는 복제하지 않았습니다. 워드마크는 시안용이며 공식 로고가 아닙니다. Pexels 사진은 실제 학원 사진이 아닌 학습 장면 예시로 표시하며, 출처는 ASSETS.md와 페이지 하단에 기재했습니다.

초기 시안도 사용자의 로컬 열림 프로젝트를 읽었지만, 실제 공개 화면의 사진 중심 구성까지 충분히 반영하지 못했습니다. 해당 로컬 버전과 원격 저장소 버전도 서로 달랐습니다. 2차에서는 실제 공개 화면을 기준으로 반복 카드와 장식용 도형 배치를 줄였습니다.

## 콘텐츠 수정

`design.mjs`의 문구를 수정한 후 `npm run build`로 docs를 갱신합니다. 스타일은 `design.css`, 동작은 `ui.js`, 계산·메모 로직은 `math.mjs`에서 관리합니다. 배포 전 `npm run check`를 실행합니다. 이 프로젝트는 정적 안내 사이트이며 회원·결제·개인정보 수집 기능은 없습니다. 상담 메모는 브라우저 화면에서만 만들며 전송·저장하지 않습니다.
