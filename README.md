# 하나수학앤독서학원 홈페이지

독립 프로젝트로 제작한 반응형 홈페이지 디자인 시안입니다.

## 실행

Node.js 설치 후 `npm run build`, `npm run check`, `npm start`를 실행합니다. 별도 패키지 설치는 필요하지 않습니다. GitHub Pages 배포 대상은 `main` 브랜치의 `/docs`입니다.

## 구성

- 첫 화면에서 초등수학, 독서논술 또는 학원 홈페이지로 이동합니다.
- 학습 노트: 직접 조작하는 둘레·넓이 도형과 풀이
- 학원 소식: 사용자 제공 블로그 연결
- 상담 안내: 개인용 상담 준비 메모 생성·복사 및 FAQ
- 모바일 메뉴, 키보드 탐색, 움직임 줄이기 설정 대응

## 확인 상태

학원 공식 블로그(nowclasssw)의 카테고리와 원문에서 교육과정, 학원 주소, 등록번호, 문의 채널을 확인했습니다. `academy-archive.mjs`에서 선별한 게시물의 분류, 작성일, 제목, 요약을 관리합니다.

현재 홈페이지는 검색 색인을 제한합니다. 교육과정 설명은 공식 블로그를 요약하고 온라인 학습 노트는 별도로 제작했습니다. 사업 정보 검증 후 공식 운영본으로 전환해야 합니다.

2차 디자인은 열림협동조합의 실제 공개 화면(https://yeollimcoop.ivyro.net/review/index.html)을 열어 확인했습니다. 넓은 사진, 명확한 글자 위계, 여백 중심의 구성을 참고했고, 학원에 맞게 블루·옐로 포인트와 공책을 닮은 학습 콘텐츠로 재구성했습니다. 열림의 사진이나 소스 코드는 복제하지 않았습니다. 워드마크는 시안용이며 공식 로고가 아닙니다. Pexels 사진은 실제 학원 사진이 아닌 학습 장면 예시로 표시하며, 출처는 ASSETS.md와 페이지 하단에 기재했습니다.

초기 시안도 사용자의 로컬 열림 프로젝트를 읽었지만, 실제 공개 화면의 사진 중심 구성까지 충분히 반영하지 못했습니다. 해당 로컬 버전과 원격 저장소 버전도 서로 달랐습니다. 2차에서는 실제 공개 화면을 기준으로 반복 카드와 장식용 도형 배치를 줄였습니다.

## 콘텐츠 수정

`design.mjs`의 문구를 수정한 후 `npm run build`로 docs를 갱신합니다. 스타일은 `design.css`, 교실 체험은 `ui.js`, 학부모 화면은 `parent-pages.mjs`와 `parent-portal.mjs`에서 관리합니다. 배포 전 `npm run check`를 실행합니다. 상담 메모는 브라우저 화면에서만 만듭니다.

## 학원 담당자의 학부모 공간 운영

Supabase에서 하나수학앤독서학원 프로젝트의 Table Editor를 엽니다.

1. `academy_students`에 학생의 표시 이름을 입력합니다.
2. 첫 가입은 `academy_invitations`에 확인한 보호자의 이메일(소문자)과 학생을 입력합니다. 저장할 때 생성된 일회용 `code`를 해당 보호자에게 개별 전달합니다. 기본 유효기간은 7일입니다.
3. 보호자가 홈페이지의 학부모 공간에서 **처음 오셨나요? 회원가입**을 열고 이메일, 새 비밀번호, 코드를 입력하면 해당 학생이 연결됩니다. 기존 계정에 형제·자매를 추가할 때는 Authentication의 사용자 ID와 학생 ID를 `academy_guardians`에 연결합니다. 보호자 관계를 확인한 후 처리합니다.
4. `academy_records`에 학생별 수업 날짜, 과목, 수업 내용, 과제를 입력합니다. `academy_lessons`에는 요일(월요일 1, 일요일 7)과 한국 현지 수업 시간을 입력합니다.
5. `academy_notices`에 등록한 공지는 자녀가 연결된 모든 보호자가 봅니다. `academy_events`에서 학생을 비우면 공통 일정이 되고, 학생을 지정하면 해당 보호자에게만 표시됩니다.
